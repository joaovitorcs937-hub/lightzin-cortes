Política de privacidade

Atualizada em 26 de novembro de 2026.

Quem usa. O Lightzin Cortes Postador é usado só pelo dono do canal Lightzin Cortes, no computador dele. Nenhuma outra pessoa faz login e não coletamos dados de outras pessoas.

O que acessamos no TikTok. Com a autorização do dono do canal, a ferramenta usa a API de postagem do TikTok para:

  • ler o nome e a foto do perfil @lightzincortes, para conferir que está postando no perfil certo;
  • enviar e publicar os nossos vídeos nesse perfil.

O que acessamos no YouTube. Com a autorização do dono do canal, a ferramenta usa a API do YouTube para enviar vídeos ao canal @lightzinbrc, conferir o nome do canal e ler as estatísticas dos nossos próprios vídeos. O uso segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

O que não fazemos. Não lemos mensagens, seguidores, contatos ou dados de outros usuários. Não apagamos nem editamos vídeos de ninguém.

Onde os dados ficam. As autorizações (tokens) ficam guardadas só no computador do dono do canal, fora de qualquer repositório público. Nada é vendido, compartilhado com terceiros ou usado para publicidade.

Como cancelar. O dono do canal pode tirar o acesso a qualquer momento: no TikTok, em Configurações e privacidade → Segurança → Apps e serviços; no Google, em myaccount.google.com/permissions. Ao cancelar, a ferramenta para de funcionar e o acesso salvo é apagado.

Contato. Pelos perfis tiktok.com/@lightzincortes ou youtube.com/@lightzinbrc.

Privacy Policy (English)

Last updated November 26, 2026.

Who uses it. Lightzin Cortes Postador is used only by the owner of the Lightzin Cortes channel, on their own computer. No one else logs in, and we do not collect data from anyone else.

What we access on TikTok. With the channel owner's authorization, the tool uses TikTok's Content Posting API to:

  • read the display name and avatar of the @lightzincortes profile, to confirm it is posting to the right account;
  • upload and publish our own videos to that profile.

What we access on YouTube. With the channel owner's authorization, the tool uses the YouTube API to upload videos to the @lightzinbrc channel, confirm the channel name, and read statistics of our own videos. This follows the Google API Services User Data Policy, including the Limited Use requirements.

What we do not do. We do not read messages, followers, contacts or any other user's data. We do not delete or edit anyone's videos.

Where data is stored. Authorizations (tokens) are stored only on the channel owner's computer, outside any public repository. Nothing is sold, shared with third parties, or used for advertising.

How to revoke. The channel owner can revoke access at any time: on TikTok in Settings and privacy → Security → Apps and services; on Google at myaccount.google.com/permissions. Once revoked, the tool stops working and the saved access is deleted.

Contact. Through tiktok.com/@lightzincortes or youtube.com/@lightzinbrc.
